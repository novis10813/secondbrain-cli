## Config: vault settings

Each vault managed by SecondBrain CLI has a local config file at `.secondbrain/config.json`.
This file is read and written by `ConfigManager` and can be inspected or modified via the
`sb config` command group.

## Config file

Key fields include:

- `vaultPath`: absolute path to the vault root.
- `dailyNotesFolder`: relative folder for daily notes (e.g. `Daily`).
- `templatesFolder`: relative folder for templates (e.g. `Templates`).
- `dbPath`: absolute path to `.secondbrain/index.db`.

You normally do not edit this file by hand; use CLI commands instead.

## Commands

### List all config values

```bash
sb config list
```

Prints the current config for the resolved vault.

### Get a specific key

```bash
sb config get dailyNotesFolder
sb config get templatesFolder
```

Returns the value of a single key.

### Set a key

```bash
sb config set dailyNotesFolder Daily
sb config set templatesFolder Templates
```

Only certain keys are editable (such as `dailyNotesFolder` and `templatesFolder`). Changes are
written back to `.secondbrain/config.json`.

For how the vault is resolved (env, cwd, default), see `docs/vault.md`.
